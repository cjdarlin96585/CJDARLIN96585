# CJDARLIN96585 — Official Website Concept

A responsive English-language brand website for **CJDARLIN96585**, Home & Decoration.

## Brand
- Primary: Dark Navy `#0F172A`
- Accent: Electric Blue `#3B82F6`
- Secondary: White `#FFFFFF`
- Style: Modern & Professional
- Tagline: Create a Home You Love.

## Open locally
Open `index.html` in any modern browser. No build tools or installation required.

## Publish with GitHub Pages
Upload `index.html` and the `assets` folder to the root of a GitHub repository. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, and save.

## Notes
- Interior photography is loaded from Unsplash and requires internet access.
- The official generated logo is provided as `assets/logo.png` for use in branding. The site uses a lightweight text/house header mark for readability.
- This is a brand showcase, not an e-commerce store. No inventory, checkout, or payment processing is implemented.
- The contact form prepares a copyable message; it does not send or store messages. Add a real verified email address or form backend before launch.
- Replace illustrative photography and verify usage rights before commercial deployment.
